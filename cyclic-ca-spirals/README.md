# cyclic-ca-spirals

A cyclic cellular automaton on a torus: every cell has one of n colors on a circle and moves on to the next color as soon as at least `threshold` of its neighbors (4 or 8) already carry it. From noise this grows blocks of color and then spirals around "demons", 2x2 blocks around which the color circle winds. The demo counts them as the winding number of every 2x2 block (the color steps around it, each the short way around the circle, divided by n), marks them with rings when there are few, and plots the count on a log scale. Spirals come in pairs: on a torus the signed total is exactly 0, which `test.cpp` checks on random fields. The count has a limit: a step of exactly n/2 between neighbors has no short way around the circle, so sharp fronts count as demons too (with the Moore neighborhood and n = 16, 51 of 54 counted blocks carried such a step, seed 11 on the 160x96 field after 1500 steps; with von Neumann and n = 12 it was 0 of 28). The status line waits for the moment the whole grid repeats itself. Measured on a 64x64 torus from noise, seeds 1 to 8, threshold 1: with the Moore neighborhood the period is n for every n from 3 to 16 in all eight seeds, with von Neumann it is n for n = 3 to 6, 8 and 10, and n + 1 for the odd n from 7 up (7 of 8 seeds at n = 7, all eight at 9 and 11). At larger n some von Neumann seeds end in one color (period 1) or at n + 2. A threshold above 1 mostly freezes the noise. Two switches show typical mistakes: updating in place instead of with a second buffer (a color wave can then cross the grid within one step, and the result is no longer mirror-symmetric), and a color circle without the wrap from n-1 to 0 (nothing can turn, the grid freezes into blocks of the last color). The automaton, the demon count, the series for the plot and the period detector are in `logic.hpp` and covered by `test.cpp`, with numbers that were first measured by a separate throwaway program.
