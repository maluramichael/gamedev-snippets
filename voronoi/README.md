# voronoi

Voronoi cells in a WebGL2 fragment shader. In the "sites" mode up to 48 points drift over the canvas on the CPU (fixed steps with an accumulator, bouncing off the walls) and go to the GPU as a uniform array; per pixel the shader finds the nearest and second nearest point by brute force, colors the cell by a hash of the point's id and measures the exact distance to the cell border from the perpendicular bisectors. The "worley" mode drops the point list: every lattice cell owns one feature point from an integer hash and a pixel only checks the 3x3 cells around it, so the pattern covers an endless plane and zooms with the mouse wheel. Chips switch the metric (euclid, manhattan, chebyshev), the borders, the isolines and one step of Lloyd relaxation, which is computed on the CPU on a 120x54 grid. The shader math is mirrored in `logic.hpp` and tested natively (`test.cpp`: nearest and ties, bisector distance, metrics on the 3-4-5 triangle, Lloyd, hash golden values, Worley bounds), the rendering needs a browser.
