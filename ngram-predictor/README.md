# ngram-predictor

Rock paper scissors against an AI that only counts. After every round it adds the run of the last N moves to a table (N = 1 to 4). To guess the next move it takes the last N-1 moves as a window, looks up which move followed that window most often and plays the move that beats it. Every possible run gets one free occurrence (as in Game AI Pro, chapter 48), and a window that was never seen falls back to a shorter one. You play with R, P and S or let a simulated player with a habit take over: a loop of four moves, a cycle of three or a fixed bias, each with 12 percent random slips. The chart shows how often the AI guessed right over the last 20 rounds against the 33 percent of a coin flip, the table shows the counts the guess is made from. Chips set the order N and how often the AI ignores its own guess. The logic (counts, fallback, hit rate, simulated players) is in `logic.hpp` and covered by `test.cpp`.
