# water-ripples-2d

The classic 2D wave equation on a 240x135 height field (`next = (left + right + up + down) / 2 - prev`, then damping), stepped on the CPU at a fixed 120 steps per second. Every frame the heights go to the GPU as an `R32F` texture, and a WebGL2 fragment shader computes the normal from the height gradient, refracts a procedural tile floor along it and adds a specular highlight. Click and drag to make waves, the chips set the damping and switch the rain. The simulation is tested natively (`test.cpp`: hand-computed steps, symmetry, energy, damping, border, the 0.5 stability limit), the rendering needs a browser.
