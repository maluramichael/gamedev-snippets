# starfield-parallax

A flight through a starfield, done two ways. The layered version keeps every star as a 2D point on one of three layers with a fixed pixel speed, which looks like three sheets sliding past each other. The perspective version keeps 5200 stars as 3D points in a periodic box around the camera, projects them with x / z and flies the camera, so speed, size, brightness and the motion streaks all fall out of the same division. The mouse steers the vanishing point, the wheel changes the speed, a top view shows where the stars really are. Two chips switch on the classic mistakes: respawning a star at a random depth (stars pop into view, orange rings mark them, and the far field thins out) and dividing by z without a near test (orange lines shoot across the picture). The logic is in `logic.hpp` and covered by `test.cpp`.
