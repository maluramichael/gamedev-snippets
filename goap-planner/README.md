# goap-planner

Goal-oriented action planning in a small world: a guard in a room, a goal ("guard dead") and a few actions, each with preconditions, effects and a cost. No script says in which order to act, an A* search over world states finds the cheapest plan. Pick a soldier, an assassin or a rat (same goal, different actions) and watch the plan with the cost of each step. Click the door to lock or barricade it, the agent replans at its next step, and the rat, who cannot kick or climb, finds no plan and patrols instead. "Script" runs the plan written for the free door as a fixed list and shows where it gets stuck. "Crates" adds objects that do not matter for the goal: the plan stays the same, with nine crates the forward search expands 930 nodes instead of 12 (free door, 8652 instead of 13 with the door barricaded), while the backward search from the goal, which only follows what the goal needs, goes from 14 to 46 (21 to 66). The world, the actions and both searches are in `logic.hpp` and covered by `test.cpp`, including a brute-force oracle that checks the cost of every plan.
